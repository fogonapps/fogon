# El Forzudo

Tu cuaderno de entrenos: rutinas, descanso, récords y rangos. Sin anuncios ni rastreo; tus datos se quedan en tu teléfono.

Una app de [Fogón](https://github.com/fogonapps/fogon): apps de Android libres, hechas en casa.

## Instalar

- **Con [Obtainium](https://github.com/ImranR98/Obtainium)** (se actualiza sola): Añadir aplicación → pega `https://github.com/fogonapps/el-forzudo` → Añadir.
- **A mano:** baja el APK de la [última versión](https://github.com/fogonapps/el-forzudo/releases/latest) y ábrelo en el teléfono.

Este repo solo guarda las versiones para instalar. **El código está en [fogonapps/fogon](https://github.com/fogonapps/fogon/tree/main/apps/forzudo)**, con licencia GPL-3.0-or-later. Problemas o ideas: [issues de Fogón](https://github.com/fogonapps/fogon/issues).
