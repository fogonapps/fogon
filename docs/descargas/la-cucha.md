# La Cucha

Lo que comes: calorías, proteína, recetas colombianas y el menú de la semana. Sin anuncios, sin rastreo, y sin internet salvo para buscar un código de barras si tú lo activas.

Una app de [Fogón](https://github.com/fogonapps/fogon): apps de Android libres, hechas en casa.

## Instalar

- **Con [Obtainium](https://github.com/ImranR98/Obtainium)** (se actualiza sola): Añadir aplicación → pega `https://github.com/fogonapps/la-cucha` → Añadir.
- **A mano:** baja el APK de la [última versión](https://github.com/fogonapps/la-cucha/releases/latest) y ábrelo en el teléfono.

Este repo solo guarda las versiones para instalar. **El código está en [fogonapps/fogon](https://github.com/fogonapps/fogon/tree/main/apps/cucha)**, con licencia GPL-3.0-or-later. Problemas o ideas: [issues de Fogón](https://github.com/fogonapps/fogon/issues).
