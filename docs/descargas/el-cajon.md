# El Cajón

Todo lo que ves, lees y escuchas: películas, series, animes, libros y discos, con tu nota, tu reseña y tu diario. Sin anuncios ni rastreo.

Una app de [Fogón](https://github.com/fogonapps/fogon): apps de Android libres, hechas en casa.

## Instalar

- **Con [Obtainium](https://github.com/ImranR98/Obtainium)** (se actualiza sola): Añadir aplicación → pega `https://github.com/fogonapps/el-cajon` → Añadir.
- **A mano:** baja el APK de la [última versión](https://github.com/fogonapps/el-cajon/releases/latest) y ábrelo en el teléfono.

Este repo solo guarda las versiones para instalar. **El código está en [fogonapps/fogon](https://github.com/fogonapps/fogon/tree/main/apps/cajon)**, con licencia GPL-3.0-or-later. Problemas o ideas: [issues de Fogón](https://github.com/fogonapps/fogon/issues).
